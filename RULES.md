# Mandatory Spec-Driven Development (SDD)

For every new feature, you MUST invoke and follow the `spec-driven-development` skill and its complete workflow.

* **User notification:** Immediately after invoking the SDD skill, inform the user: "I'm using the `spec-driven-development` skill to guide this task through the required specification, planning, approval, implementation, and validation stages."
* Do not begin implementation until the specification and technical plan have been explicitly approved by the user and implementation has been explicitly authorized.
* Never skip approval gates or bypass mandatory prerequisites.
* Always invoke every skill applicable to the task, following its instructions and prerequisites.
* If the SDD skill, any required skill, or the Mobile Guidelines cannot be accessed, stop and report the blocker.

The SDD skill defines the workflow. Mobile Guidelines define the mobile-specific requirements and quality standards.

## Git

- Before completing any task, stage all files created, deleted, renamed, or intentionally modified as part of the task using Git.
- Never stage unrelated changes.
